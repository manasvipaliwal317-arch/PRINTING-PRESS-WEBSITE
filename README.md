# PrintCraft - Professional Printing Press Website

A modern, responsive multi-page website designed for a commercial printing press company offering offset printing, digital printing, large format printing, packaging, and custom corporate merchandise.

## 🌟 Features

- **Multi-Page Architecture**:
  - `index.html` — Homepage featuring hero section, highlighted services, featured products, statistics, and call-to-actions.
  - `about.html` — Company story, printing heritage, machinery & equipment specifications, and team.
  - `services.html` — Detailed breakdown of printing capabilities (Offset, Digital, Large Format, Packaging, Finishing).
  - `products.html` — Product catalog with categories, specifications, and direct quotation requests.
  - `pricing.html` — Transparent pricing tiers and interactive print cost calculator.
  - `gallery.html` — Visual portfolio showcasing completed client projects with category filtering.
  - `testimonials.html` — Client reviews, case studies, and trust badges.
  - `blog.html` — Industry insights, printing guides, paper weight explanations, and color tips.
  - `faq.html` — Frequently asked questions regarding file preparation, turnaround times, and shipping.
  - `contact.html` — Inquiry form, business location, operational hours, and direct contact details.

- **Design & UI**:
  - Fully responsive across mobile, tablet, and desktop screens.
  - Custom color palette with modern typography and smooth transitions.
  - Interactive elements: mobile navigation drawer, interactive quote calculator, lightbox gallery modal, and FAQ accordion.
  - High-resolution visual assets for print machinery and products.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via a local static file server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```

## 🛠️ Tech Stack

- **HTML5** (Semantic markup, SEO meta tags, OpenGraph support)
- **Vanilla CSS3** (Custom properties, Flexbox, Grid, animations)
- **Vanilla JavaScript** (Interactive components, calculators, sliders)
- **Assets** (Custom graphics and imagery)
